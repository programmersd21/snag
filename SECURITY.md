# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within `snag`, please report it responsibly rather than opening a public issue.

Please report vulnerabilities via **GitHub Security Advisories** on this repository or contact the maintainer directly at **[programmersd21@gmail.com](mailto:programmersd21@gmail.com)**.

You will receive an acknowledgement within 48 hours, followed by updates on triage and mitigation.
